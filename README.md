#  Sistema Musical

##  Sobre o Projeto

O **Sistema Musical** é um projeto desenvolvido com HTML5 e CSS3, com o objetivo de criar um sistema para organizar e gerenciar informações relacionadas ao universo musical.

O sistema possui uma interface simples, organizada e intuitiva, permitindo o acesso às funcionalidades por meio de diferentes telas.

##  Estrutura do Projeto

O projeto é composto por cinco telas principais:

1. **Login:** tela de acesso ao sistema.
2. **Menu Principal:** apresenta as opções disponíveis para navegação.
3. **Cadastro do Criador:** permite cadastrar informações dos criadores musicais.
4. **Cadastro da Obra:** permite registrar informações das obras musicais.
5. **Listagem:** apresenta os registros cadastrados de forma organizada.

##  Estilização

O projeto utiliza um único arquivo `styles.css`, responsável pela aparência de todas as páginas.

As principais características são:

- Paleta de cores definida no `:root` do CSS.
- Cores padronizadas em todas as telas.
- Botões com estilos e efeitos ao passar o mouse.
- Formulários organizados.
- Tabelas com melhor visualização.
- Layout padronizado para facilitar a navegação.

##  Responsividade

O Sistema Musical foi desenvolvido para funcionar em diferentes tamanhos de tela, incluindo:

- Computadores e notebooks.
- Tablets.
- Celulares.

O layout se adapta ao tamanho do dispositivo, proporcionando uma navegação mais confortável.
